# Blokasa

Site da **Blokasa Pisos Intertravados**: clientes conhecem os produtos, pedem orçamento de pisos intertravados,
drenantes, guias e blocos, e (em breve) se cadastram para consultar orçamentos anteriores.

| Parte | Tecnologia | Pasta |
|---|---|---|
| Front-end | React 19 + TypeScript + Vite | `frontend/` |
| Back-end | .NET (Web API) | `backend/` (próxima etapa) |
| Banco de dados | MySQL | `database/` (próxima etapa) |

Design de referência: [Figma](https://www.figma.com/design/3aH6jvcdovkKnhkukWFdph/Untitled?node-id=0-1).

## Rodando o front-end

```bash
cd frontend
npm install
npm run dev      # http://localhost:5173
npm run build    # gera frontend/dist
npm run lint
```
